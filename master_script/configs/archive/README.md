# Archived configurations

These 18 YAML sweep files and the demo RAG study were moved here on 12 September
2026 when the active study narrowed to AMIA and Reference. Original file bytes
are preserved; `manifest.json` records their SHA-256 hashes. They are excluded
from the dashboard's active config list.

The active file is `../amia_reference_rag_master.yaml`. The archived larger
research profile originally required a separately prepared `research_data/`
folder relative to its own location. To reuse it, restore a copy to the active
directory or update its study path deliberately. Archived configurations are
historical examples, not the recommended current sweep.
