## Source blocker B-01: WBC defines two different window schedules

**Priority:** blocking for strict source fidelity; not yet classified as an implementation defect. **Confidence:** high; the printed PDF page was visually checked.

Authority: Chen et al., *Window-based Membership Inference Attacks Against Fine-tuned Large Language Models*, arXiv:2601.02751v2 (5 March 2026), §4.1.4, Eq. (12), p. 7; §5.3.2; Appendix C.1.5, p. 23. Local source: [WBC PDF](../../papers/summary/papers/wbc.pdf). The copy at `written_paper/reference_papers/Chen_2026_WBC.pdf` also contains the same conflicting statements.

For ten windows between 2 and 40 tokens, the stated equation is:

`w_k = round(2 * 20 ** ((k - 1) / 9)), k = 1,...,10`.

Its values are `[2, 3, 4, 5, 8, 11, 15, 21, 29, 40]`.

Appendix C.1.5 instead gives `[2, 3, 4, 6, 9, 13, 18, 25, 32, 40]` as the values generated by that equation. Six entries differ. Ordinary rounding conventions cannot reconcile the lists. Different window schedules change the windows scored and can change membership scores and results; choosing one is not a behavior-preserving simplification.

**Required resolution:** establish whether Eq. (12) or the literal experimental list governs reproduction, ideally with an author clarification or corrected source. Alternatively, explicitly authorize continuing with this ambiguity recorded and WBC window-schedule fidelity left unresolved. Do not silently select a schedule or label either choice an exact reproduction of both statements.

The unambiguous WBC aggregation baseline is Eq. (13) and Algorithm 1: calculate the positive-window fraction separately for each size, then average those fractions uniformly across sizes. No implementation verdict has been issued here.

**Why work stopped:** the user’s prompt explicitly says, “If a paper is ambiguous or a required paper is missing from the reference folders, state this and stop rather than guessing at the intended theory.” This pause comes from that user instruction, not from an inferred approval rule.
